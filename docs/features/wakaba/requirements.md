# wakaba 要件定義

## 背景・目的

個人開発者が OSS へ貢献しようとしても、活動の可視化やゴール設定の仕組みがなく、モチベーションが続きにくい。既存ツール (Amazon oss-contribution-tracker / Netflix osstracker) は組織向けであり、GitHub の内蔵統計はゴール設定機能を持たない。

Wakaba は個人開発者が自分の OSS 貢献活動に対してゴールを設定し、進捗を可視化・追跡できるセルフホスト型ツールを提供する。これにより、モチベーションの維持と継続的な OSS 貢献を支援する。

## ターゲットユーザー

- OSS への貢献に意欲を持つ個人開発者
- 自身の貢献活動を記録・振り返りたい個人開発者
- データをセルフホスト環境で管理したいプライバシー意識の高い開発者

## スコープ

### In Scope

- GitHub OAuth による認証
- GitHub API を用いた個人の貢献データ (commit / PR / issue / review) の取得・蓄積
- 期間とゴール条件を自由に設定できるゴール管理機能
- ゴール進捗ダッシュボードの表示
- 週次 Discord ダイジェスト送信 (webhook)
- Docker Compose によるセルフホスト構成

### Out of Scope

- 複数ユーザーによる組織・チーム管理機能
- GitHub 以外のプラットフォーム (GitLab / Bitbucket 等) への対応
- モバイルアプリ
- SaaS / マネージドクラウドホスティング
- 他ユーザーとのゴール共有・ランキング機能

## 機能要件

### 認証

- 個人開発者として、GitHub OAuth でログインしたい。なぜなら、新たなアカウント管理の手間なく安全にサービスを利用したいから。

### 貢献データの取得・蓄積

- 個人開発者として、GitHub API 経由で自分の貢献データ (commit / PR / issue / review) を取得・蓄積したい。なぜなら、手動入力なしに正確な活動履歴を把握したいから。

### ゴール管理

- 個人開発者として、期間とゴール条件 (例: 「今期中に 3 つの新規リポジトリへ PR をマージさせる」) を自由に設定したい。なぜなら、自分のペースで達成可能な目標を定めてモチベーションを維持したいから。

### ゴール進捗ダッシュボード

- 個人開発者として、設定したゴールに対する現在の進捗状況をダッシュボードで確認したい。なぜなら、達成度をひと目で把握して次のアクションを判断したいから。

### 週次 Discord ダイジェスト

- 個人開発者として、週に一度 Discord へ自分の貢献サマリーと進捗が自動通知されてほしい。なぜなら、意識しなくても定期的に振り返りの機会を持ちたいから。

## 非機能要件

- **セルフホスト**: Docker Compose 一式で構成し、ローカル環境または VPS 上で動作すること
- **プライバシー**: 取得した貢献データはローカル DB (PostgreSQL) にのみ保存し、外部サービスへ送信しないこと (Discord webhook は除く)
- **想定規模**: 個人利用 (単一ユーザー) を前提とした設計であること

## 受け入れ基準 (= UAT 項目)

1. ユーザーが GitHub OAuth でログインを完了したとき、自身の GitHub アカウント情報がダッシュボードに正しく表示される
2. ユーザーがデータ同期を実行したとき、GitHub API から取得した commit / PR / issue / review の件数がダッシュボードに反映される
3. ユーザーがゴール (期間・条件) を新規作成したとき、ゴール一覧にそのゴールが表示される
4. 貢献データが更新されたとき、ダッシュボードの進捗表示がゴールの達成状況を正しく反映する
5. ゴールが達成条件を満たしたとき、ダッシュボード上で達成済みステータスとして表示される
6. Discord webhook URL が設定された状態で週次ダイジェストジョブが実行されたとき、指定チャンネルに貢献サマリーと進捗が投稿される
7. Docker Compose で起動したとき、全サービス (DB / バックエンド / フロントエンド / Nginx) が正常に起動しトップページへアクセスできる

## 未決事項

- ゴール達成条件の粒度 (PR のマージ必須か、オープンで可か)
- データ同期のトリガー方式 (手動実行 / 定期スケジュール / 両方)
- 週次ダイジェストの送信曜日・時刻の設定可否
