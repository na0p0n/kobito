# ADR 002: アイデア生成における新規性しきい値

## Status

Accepted (2026-05-01)

## Context

アイデア生成ステージで類似アプリ調査を行った後、どの時点でアイデアを「却下」とするか基準が必要だった。数値スコアのしきい値は恣意的になりやすく、運用しながら調整できる言語化された基準が望ましい。

## Decision

LLM-as-judge による3段階判定を採用する。

| 判定 | 条件 | アクション |
|---|---|---|
| **却下** | 機能・UX・ターゲットが既存アプリとほぼ同一、差別化を1文で言えない | アイデア生成やり直し |
| **要確認** | 既存ジャンルだが差別化要素あり、判断が微妙 | 直也にエスカレーション |
| **採用** | 新しい切り口、または未開拓ニッチ | 次ステージへ |

### 差別化の判定軸 (LLM-as-judge に渡す観点)

- ターゲットユーザーが違うか
- 解決する課題が違うか
- UX・提供形式が違うか

### 「ほぼ同一」の実用的判断基準

「既存アプリの URL を貼れば代替できる」なら却下。

## Consequences

- 数値しきい値より判断根拠が人間に説明しやすい
- 「要確認」を設けることで境界ケースを無理に自動判定しない
- しきい値の厳密さは運用しながら「却下」「要確認」の判断実績をもとに調整できる
